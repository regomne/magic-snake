# 魔尺公式模拟器

将魔尺公式解析成可逐步播放的 3D 造型。目前支持 24、36、48、72 段魔尺。

## 公式

```text
1(1), 3(-1), 5(2)
```

- 编号表示关节；关节 1 位于第 1、2 块之间。
- `1` 为顺时针 90°，`-1` 为逆时针 90°，`2` 为 180°。
- 方向以面对该关节所依附的上一块矩形面为准。
- 重复关节会累积旋转；支持中英文逗号、分号和换行分隔。

## 几何规格

单块采用等腰直角三棱柱，直角边及挤出厚度均为 30 mm。内部渲染比例为 `1 unit = 30 mm`。相邻块由正方形面中心的轴连接，接触面保留 0.1 mm 间隙，零状态下交替排列为直条。
