# 魔尺造型工作台

可以直接设计、检查、保存和分享魔尺造型的 3D 工作台。目前支持 24、36、48、72 段魔尺。

## 直接编辑

- 点击 3D 方块选择关节，再执行顺时针、逆时针或 180° 旋转。
- 模型与公式双向同步，支持撤销、重做、一键拉直和键盘快捷键。
- 使用整数晶格和半立方体互补规则精确检查最终姿态碰撞。
- 自动保存工作区，支持命名保存、URL 分享及 JSON、PNG、分步教学导出。

## 公式

```text
1(1), 3(-1), 5(2)
```

- 编号表示关节；关节 1 位于第 1、2 块之间。
- `1` 为顺时针 90°，`-1` 为逆时针 90°，`2` 为 180°。
- 方向以面对该关节所依附的上一块矩形面为准。
- 重复关节会累积旋转；支持中英文逗号、分号和换行分隔。

也可以直接粘贴以段编号表示的上标公式，例如 `2¹ 4² 10⁻¹`，系统会自动换算为关节编号。

## 几何规格

单块采用等腰直角三棱柱，直角边及挤出厚度均为 30 mm。内部渲染比例为 `1 unit = 30 mm`。相邻块由正方形面中心的轴连接，接触面保留约 0.16 mm 间隙，零状态下交替排列为直条。
